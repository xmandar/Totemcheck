This addon made to track totems in the game. If you have the buff the icons will be colored if you are away from shaman totems its gonna be black and white, if you at all don't have the buff it shows you question mark.

Here's the commands that you can use:

/tc - will show the menu

/tc unlock - to unlock the frame to change the position of addon UI

/tc lock - lock the UI
